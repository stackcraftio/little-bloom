01. about the flower ✿

A little creative coding experiment where a flower grows from nothing.

First, the stem slowly appears. Then the leaves unfold, the petals bloom one by one, and tiny sparkles bring everything to life.

Built entirely using HTML, CSS, JavaScript and SVG — no image files, libraries or frameworks.

Just a little bit of code and a flower. ♡
